Spa Río Azul - One-page static website

Contenido:
- index.html
- style.css

Despliegue (GitHub Pages):
1) Crear un repositorio en GitHub.
2) Subir estos archivos a la rama 'main'.
3) En Settings > Pages, seleccionar 'main' y carpeta '/'.
4) La web estará en https://<usuario>.github.io/<repo>.

Conectar dominio:
- Comprar dominio en registrador.
- Añadir CNAME en repo (archivo CNAME con dominio) o configurar DNS según GitHub Pages.
- Netlify también permite subir zip y conectar dominio con certificado SSL gratis.

Coste estimado:
- Diseño y entrega: $2,000 MXN (incluido).
- Dominio: aprox. $300 - $700 MXN/año (según TLD y registrador).
- Hosting: GitHub Pages / Netlify -> gratis para sitios estáticos.

Formulario:
- El formulario en la maqueta es de ejemplo. Para producción usar Formspree, Netlify Forms o un backend.
