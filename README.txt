 Beauty Spa ByF - One-page minimalist website

Archivos:
- index.html
- style.css

Descripción:
- One-page minimalista (blanco / palo de rosa). Imágenes provisionales (Unsplash).
- Formulario redirige a WhatsApp (modificar número en index.html).
- Para publicar: subir archivos a GitHub y activar Pages (branch main, folder /).

Cambios rápidos:
- Reemplazar imágenes: busca tus fotos y cambia los src en index.html.
- Cambiar WhatsApp: busca "wa.me/521..." y pon el número real.
- Conectar dominio: crea archivo CNAME con dominio y configura DNS según GitHub Pages.
